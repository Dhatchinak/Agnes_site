# Agnes Roselin — Cinematic Birthday Website

A responsive React + Vite birthday experience personalised for Agnes Roselin, born 05 August 2004.

## Run
```bash
npm install
npm run dev
```

## Photos
Place these inside `public/photos/`:
- `hero.jpg` — best portrait
- `special.jpg` — meaningful portrait or couple photo
- `photo-01.jpg` through `photo-12.jpg`

## Audio
Place optional audio inside `public/audio/`:
- `favourite-song.mp3`
- `voice-01.mp3` to `voice-04.mp3`
- `shutter.mp3`, `page-turn.mp3`, `chime.mp3`

## Included experiences
Cinematic loader and story intro, fireflies, reactive parallax, custom cursor, glass cards with pointer light, floating photo gallery, animated lightbox with typed captions and music ducking, glowing-road timeline, CSS perspective memory tunnel, voice-note memories, unfolding letter, candle/confetti reveal, and final photo-orbit portrait sequence.
