# Secret Heart Premium V4

This version improves the Secret Heart into a more premium, cinematic, photo-friendly experience.

## Updated
- better **front password / unlock page** with split layout and Secret Heart preview
- stronger **full-screen cinematic proposal design** after unlock
- improved **photo-led story scenes** instead of plain text-heavy slides
- easier support for **new custom photos**
- warm **final proposal** and **forever keepsake** ending
- responsive mobile + desktop polish

## Add your own photos
Place them in:

`public/secret-heart/`

See this file for names:

`public/secret-heart/ADD-YOUR-SECRET-HEART-PHOTOS-HERE.txt`

## Music
Optional:

`public/audio/secret-heart-piano.mp3`

```bash
npm install
npm run dev
```
