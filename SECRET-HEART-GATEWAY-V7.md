# V7 — Two-Door Entrance

The first 4-digit birthday password screen is now the gateway to two separate experiences.

## Birthday Wishes
- Enter the existing 4-digit birthday code.
- Tap **Open Birthday Wishes**.
- The existing birthday intro, countdown, and full birthday website open exactly as before.

## Secret Heart
- On the same entrance screen, tap the new **Secret Heart** doorway.
- It opens **Our Unwritten Chapter** directly.
- No second password is required from this front gateway.
- The Secret Heart button in the birthday-site footer also opens the proposal directly for consistency.

The secondary Secret Heart doorway is intentionally visually quieter than the main birthday button so the entrance remains clean and elegant.
