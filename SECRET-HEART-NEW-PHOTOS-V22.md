# Secret Heart — New Photos V22

The Secret Heart photo system is now completely separated from the main website photos.

## Folder
`public/secret-heart/new-photos/`

## Photo slots
- `agnes-main`
- `memory-01` through `memory-06`
- `proposal-main`
- `proposal-small`
- `keepsake`

Supported formats: JPG, JPEG, PNG, WEBP.

All paths are managed in one file:
`src/data/secretHeartPhotos.js`

The Secret Heart experience no longer falls back to `/public/photos` for these screens.
