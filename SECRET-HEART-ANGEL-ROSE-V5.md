# Secret Heart Angel Rose V5

This version redesigns Secret Heart with a softer, more beautiful proposal experience.

## What changed
- better **password / unlock screen**
- soft **rose / ivory aesthetic**
- new **teddy hug opening animation** after correct password
- stronger **proposal story structure**
- improved **mobile alignment** inside Secret Heart
- support for your **own new photos** via `public/secret-heart/`
- final keepsake after she says yes

## Add your own photos
Check:
`public/secret-heart/ADD-YOUR-SECRET-HEART-PHOTOS-HERE.txt`

## Optional music
Add:
`public/audio/secret-heart-piano.mp3`

## Run
```bash
npm install
npm run dev
```
