# Secret Heart Proposal V2

The Secret Heart has been redesigned into a full-screen editorial/cinematic proposal instead of a stacked-card interface.

Flow:
1. Press-and-hold heartbeat entrance
2. Four portrait-led memory scenes
3. Personal letter with optional voice note
4. Large final proposal composition
5. Respectful "I need a little time" path
6. Celebration and persistent private keepsake after Yes

Optional voice note:
`public/audio/secret-heart-voice.mp3`

The accepted state is stored locally in `secretHeartProposalYesV2` so the old proposal test state does not skip the new experience.
