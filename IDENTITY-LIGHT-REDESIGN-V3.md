# Secret Heart — Identity Page Light Redesign V3

Updated the **“Every name still leads back to you.”** scene with a completely new light editorial layout.

## What changed
- Removed the old arched/circular portrait frame and orbit design.
- Added a clean rectangular portrait card with soft depth only.
- Moved the main emotional story to the left and the portrait/name cloud to the right.
- Added eight floating name pills around the portrait without enclosing the photo in a heavy frame.
- Added a lighter “A Little Truth” card and a stronger pink CTA.
- Added subtle blush/cream decorative glows and a faint Agnes “A” watermark.
- Added dedicated tablet and mobile layouts.

## Logic kept unchanged
The Secret Heart flow, password, scene navigation, music, memories, and all later scenes remain unchanged.

Run:

```bash
npm install
npm run dev
```
